# Dylan's Nature Library - Bird of Paradise

A student's tribute to the wonders of nature, featuring the Bird of Paradise flower (Strelitzia reginae).

## About

This website was created by Dylan as:
- A tribute to nature itself
- A practice project for HTML programming
- An opportunity to experiment with web design while expressing love for the natural world

## Features

- Interactive entry screen with guided tour
- Comprehensive information about the Bird of Paradise:
  - Symbolism and personal meaning
  - Scientific origins and naming
  - Global significance across countries
  - Fascinating stories and cultural significance
- Photo gallery with Bird of Paradise images
- Responsive design with Bird of Paradise themed colors
- Developer mode for easier editing during development

## Technology

- HTML5
- CSS3
- JavaScript (vanilla)
- BrowserSync for live reloading

## Development

To enable developer mode (skip intro screen):
1. Click the "Skip Intro (Dev Mode)" button in the bottom-right corner
2. This preference is saved in localStorage
3. To disable, click the button again

## Images

All images are stored in the `images/` directory:
- background.png - Main background image
- flower1.png - Bird of Paradise display
- flower2.jpg - Natural beauty shot
- flower3.jpg - Perfect bloom photo
